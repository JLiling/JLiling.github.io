隐私协议

本站（栗子的糖果屋 / exschwi.github.io）是一个使用 Hexo 搭建的静态博客。本页尽可能如实地说明：当你访问本站时，哪些信息会被处理、由谁处理，以及本站自身和第三方服务各自的边界。

本站自身的数据处理

本站是纯静态站点，不主动收集、存储你的个人信息。

本站没有账号系统、登录、评论、支付、广告，也不会收集你的邮箱、手机号、姓名等任何需要你主动填写的资料，不建立用户画像，不做行为追踪。

你访问本站时产生的请求，会由托管平台（GitHub Pages）在服务日志层面自然记录（例如访问 IP、请求时间、访问路径），这部分属于托管服务的基础运维数据，本站作者不会主动读取或分析。

第三方服务

本站的部分功能依赖第三方服务。它们会在你的浏览器加载资源或请求数据时，收到你的请求信息（例如 IP 地址、User-Agent 等）。这与”本站收集数据”是两回事：这些信息由对应第三方处理，其保存方式、处理用途和保留时长，以该第三方自己的隐私政策为准。

服务作用备注
不蒜子（busuanzi.ibruce.info）统计站点 PV / UV全站加载，用于展示访问量
网易云音乐 Meting 接口（api.injahow.cn）加载吸底播放器的歌单全站加载，返回音乐播放所需数据
jsDelivr（cdn.jsdelivr.net）提供主题第三方脚本 CDN全站加载
BootCDN（cdn.bootcss.com）提供页面加载进度条脚本全站加载
elemecdn（npm.elemecdn.com）提供页脚挂件等样式与脚本全站加载
shields.io（img.shields.io）页脚徽标图片全站加载
B 站图床（i0.hdslb.com）追番页的番剧封面图仅追番页加载

追番页的番剧数据在作者构建博客时生成并随站点静态部署，访客浏览器不会直接请求 Bilibili 的接口；仅在加载番剧封面图时会向 B 站图床发起请求。

本地存储

本站为了实现主题功能，会在你的浏览器中写入少量本地数据，均为浏览器本地行为，不会上传给本站：

  • localStorage：记住深色模式偏好、侧栏状态、首页欢迎弹窗是否已展示、音乐播放器设置等
  • sessionStorage：记录本次会话中已弹出的提示
  • Cookie：记录浏览器版本提示是否已弹出，以及不蒜子统计的去重计数

这些数据随时可以在浏览器设置中清除，清除后不影响本站的正常浏览。

隐私页自身的说明

本页此前内嵌了一段来自模板的第三方 UA 解析脚本（cdn.meuicat.com）和一个未被实际调用的 IP 定位函数（api.qjqq.cn）。这两处均为模板遗留，且并非本站必要功能，现已移除。当前本页不会再向任何第三方发起用于”展示访客 IP / 浏览器信息”的请求。
